# Skillpath

A learning-platform landing page built in Framer as part of a junior developer assignment.

## Features

- Responsive Hero, Courses and Footer sections
- Courses loaded from a live API
- Dynamic INR/USD pricing
- Loading, error and empty states
- Retry functionality
- Responsive 3/2/1 course grid
- Framer property controls
- Two-line course descriptions
- Refundable badge
